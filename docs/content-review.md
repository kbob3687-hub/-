# 公开投稿审核

## 两道入口都检查

`POST /api/appraise` 在出票前审核原话、标题和照片；`POST /api/artifacts` 在写入前再次审核最终原话、标题、照片以及所有展览文案。直接请求入库接口也需要通过审核，不信任客户端鉴定结果。只保存审核过的白名单字段。

安全与主题分别判断。正向情绪不是拒绝依据，工作中的走神、废弃的努力也可以入馆。主题拒绝主要成果、教程、推广以及无关灌水。安全判断需要结合上下文，不能把正常讨论、受害经历或求助简单当成违规词。

## 配置

在 `.env.local` 或服务器环境填写 `CONTENT_REVIEW_MODEL`（支持图片 `image_url` 输入及 JSON 输出的视觉模型）、`CONTENT_REVIEW_BASE_URL`、`CONTENT_REVIEW_API_KEY`。接口采用兼容的 `/chat/completions` 协议；审核 key 和 base 留空时复用 `AI_API_KEY` 和 `AI_BASE_URL`。密钥只在服务端使用。

审核独立于编目模型及 `IS_OFFLINE_DEMO`，没有配置、超时、限流、返回格式异常或审核不确定时，返回 503 并暂停公开投稿，不降级放行。已收藏内容的阅读不受影响。用户的输入和照片仍保留在当前表单中，可重试。

此前使用 `https://api.qiyuanapi.cc/v1` 和中转模型名 `deepseek-v4.1`。2026-09-27 用合成测试验证了正向片段、工作中发呆、成果内容、违法招揽的区分；图片识别能辨认测试图的颜色和形状，并拦截文字正常但附图含违法招揽的投稿。仅为有限样例验证，不保证零漏检。

该服务设置 `CONTENT_REVIEW_DISABLE_THINKING=true`，发送 `thinking: {type: disabled}` 与 `reasoning_effort: none`，避免短输出预算被思考占用。其他服务不支持这些参数时应保持 false。曾观察到并发请求返回 429；限流会暂停该次投稿，用户可重试。

422 返回 `reason: safety | theme`；503 返回 `reason: unavailable`。前端不展示模型生成的拒绝解释，使用固定文案，避免回显有害内容。

## 私密记录与边界

深库特藏保持本机存储，不发送至公开审核接口，仅有本地主题提示；不宣称私密记录经过完整安全审核。模型审核不能保证零漏检，正式运营仍需要举报与馆方下架机制。已有馆藏不会自动补审。

上线前应在所选服务验证：开心地看云、加班时走神、被废弃的报告允许；实用教程或成果推广按主题拒绝；隐私泄露或违法招揽按安全拒绝；正常讨论敏感话题不误拒；普通文字配违规图片仍拒绝；服务中断不入库。须验证实际图像识别，不能使用仅支持文字的模型。

## 投稿接口容量防护

默认模型调用并发 1，最多排队 12 个调用，排队 45 秒未轮到则返回 503；队列满返回 429。审核与在线编目共用队列，阅读与本机深库不经过队列。一次公开投稿一般使用两次审核，启用在线编目时另加一次调用。

`SUBMISSION_MODEL_DAILY_LIMIT` 默认 1000 次，按 UTC 日期（北京时间每天 08:00）重置。计数在外部调用前预留，失败调用也计数；记录保存在忽略上传的 `data/model-budget.json`，服务重启不清零，记录损坏时暂停调用。它是调用次数上限，金额上限还需服务商后台设置；先贤检索等其他入口不在本次投稿额度内。

前端发布发送稳定的 `Idempotency-Key`，服务端绑定白名单内容的 SHA-256。并发重试合并为一次审核和写入；已入库重试直接返回原编号。修改内容必须重新审核，其他用户独立提交相同原话不会因为同一句话被合并。旧客户端未带 key 时按完整内容去重。内部标识不出现在公开响应中。

请求实际字节上限 2 MiB，非法 JSON 返回 400，超限返回 413。用户投稿最多 5000 件，整个馆藏 JSON 默认最多 100 MiB，通过 `SUBMISSION_ARCHIVE_MAX_COUNT` 和 `SUBMISSION_ARCHIVE_MAX_BYTES` 调整；满时返回 507，不删除已有记录。检查在审核前和串行写入时各执行一次，避免并发越过上限。

容量拒绝使用固定文案，前端保留表单供重试。部署仅支持单 Node 进程；多进程或多服务器前应改用数据库及共享队列/额度。上线同步代码后重新构建、重启服务，默认参数无需额外配置。

## 官方 DeepSeek 图片实测

2026-09-27 本地改用 `https://api.deepseek.com` / `deepseek-flash`，模型列表接口认证成功。使用实际服务和项目审核函数顺序发送三次合成测试，均 HTTP 200：独立识图准确返回左侧蓝色三角形、右侧橙色圆形；正常文字搭配该图片通过审核；同一正常文字搭配含违法枪支交易招揽文字的测试图，返回 safety 拒绝。两次审核各约 0.85 秒。沿用关闭思考与 JSON 输出参数，均正常接受。

测试没有调用入库接口，额度记录与合成图片放在忽略上传的临时目录，不改真实馆藏。这只验证有限样例与实际图片输入，尚不代表复杂照片、其他违规类别或并发负载全部验证通过。
